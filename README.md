# 📈 KoronaPay Spread Checker

Telegram бот для мониторинга и сравнения курсов валют между KoronaPay, обменными пунктами Грузии и биржей Bybit для поиска выгодных арбитражных возможностей.

## 📋 Описание

Этот проект представляет собой Telegram бота, который автоматически отслеживает курсы валют из различных источников и находит наиболее выгодные спреды для арбитража:

- **KoronaPay** - курсы денежных переводов
- **Обменные пункты Грузии** - локальные курсы обмена валют
- **Bybit** - курсы криптовалютной биржи

Бот анализирует полученные данные и уведомляет пользователей о выгодных возможностях для арбитража.

## ⚡ Возможности

- 📊 Мониторинг курсов валют в режиме реального времени
- 🔄 Автоматическое сравнение спредов между различными платформами
- 📱 Уведомления через Telegram о выгодных возможностях
- 🌍 Поддержка грузинских обменных пунктов
- 💱 Интеграция с криптобиржей Bybit

## 🛠️ Технологии

- **Python** - основной язык программирования
- **pyTelegramBotAPI (telebot)** - библиотека для работы с Telegram Bot API

### Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/aromanchev/koronapay-spread-checker.git
cd koronapay-spread-checker
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл конфигурации `.env`:
```env
BOT_TOKEN=your_telegram_bot_token_here
```

4. Запустите бота:
```bash
python main.py
```

## 📊 Как работает

1. **Сбор данных**: Бот периодически опрашивает API следующих сервисов:
   - KoronaPay API для получения курсов переводов
   - API обменных пунктов Грузии
   - Bybit API для получения криптовалютных курсов

2. **Анализ спредов**: Программа сравнивает курсы и вычисляет потенциальную прибыль от арбитража

3. **Уведомления**: При обнаружении выгодных возможностей бот отправляет уведомления пользователям

## 🎯 Использование

### Основные команды бота:

- `/start` - Запуск бота и получение приветственного сообщения
- `/auto_messaging` - Рассылка информации по спреду
- `/stop_messaging` - Остановка рассылки информации по спреду
- `/spread` - Показать лучшие спреды на данный момент

## ⚠️ Важные замечания

- **Риски арбитража**: Арбитражные операции всегда несут финансовые риски. Используйте информацию только в ознакомительных целях.
- **Задержки**: Курсы валют могут изменяться быстро, учитывайте возможные задержки при выполнении операций.
- **Комиссии**: При расчете прибыли учитывайте комиссии всех используемых сервисов.
